**Production Endpoint:** `https://sapi.xt.com`

**Type:** GET

**Description:** `/v4/withdraw/history`

Sign the request with the **sub-account's own API Key**. The `QUERY` permission is sufficient.

### Parameters

| Name | Type | Mandatory | Default | Description | Ranges |
| --- | --- | --- | --- | --- | --- |
| currency | string | false | - | Currency name | - |
| chain | string | false | - | Transfer network | - |
| status | string | false | - | Withdrawal status | SUBMIT, REVIEW, AUDITED, AUDITED_AGAIN, PENDING, SUCCESS, FAIL, CANCEL |
| fromId | long | false | - | Record id from the previous page | - |
| direction | string | false | NEXT | Pagination direction | NEXT, PREV |
| limit | int | false | 10 | Items per page | 1-200 |
| startTime | long | false | - | Query start time | Millisecond timestamp |
| endTime | long | false | - | Query end time | Millisecond timestamp |

### Request Example

```bash
curl -X GET 'https://sapi.xt.com/v4/withdraw/history?currency=usdt&chain=Ethereum&limit=100' \
  -H 'validate-algorithms: HmacSHA256' \
  -H 'validate-appkey: {subAccountAccessKey}' \
  -H 'validate-recvwindow: 60000' \
  -H 'validate-timestamp: {timestamp}' \
  -H 'validate-signature: {signature}'
```
