# 盘面分析

由 `xt-market-analysis` skill 驱动。把 XT 行情与 **TradeKit 聚合公开市场数据**结合，输出结构化的多空博弈判断。无需 API Key。

---

## 数据维度

| 工具 | 看什么 | 参数 |
|------|--------|------|
| `market_open_interest` | 全市场 U 本位永续未平仓量（币量 + 美元价值）——仓位规模 | `symbol` |
| `market_long_short_ratio` | 多空账户比时间序列（`>1` 净多，`<1` 净空）——散户情绪 | `symbol`, `period`（`5m/1H/1D`）, `limit` |
| `market_taker_volume` | 主动买/卖成交量对比——真实买卖压力 | `symbol`, `period`, `limit` |
| `market_recent_liquidations` | 近期强平记录（方向/数量/价格/时间）——杠杆出清 | `symbol`, `limit` |
| `market_fear_greed` | 恐惧贪婪指数（0 极度恐惧 ~ 100 极度贪婪） | `days` |
| `market_global_overview` | 全球总市值、24h 成交额、BTC/ETH 市值占比 | — |
| `market_sentiment_snapshot` | **组合视图**：恐惧贪婪 + 24h 主动买卖比 + 最新多空比 | `symbol` |

配合 XT 侧的价格、K 线、盘口与资金费率（见[行情查询](./MarketData)）。

---

## 怎么读这些指标

**价格 × 未平仓量**

| 组合 | 含义 |
|------|------|
| 价涨 + OI 涨 | 新多入场，趋势有资金支撑 |
| 价涨 + OI 跌 | 空头回补推动，持续性存疑 |
| 价跌 + OI 涨 | 新空入场 |
| 价跌 + OI 跌 | 多头止损离场，去杠杆 |

**资金费率 + 多空比**
费率显著为正且多空比高企，说明多头拥挤、持仓成本高，容易出现多杀多。反之亦然。

**主动买卖量**
多空比反映的是**账户数**，主动买卖量反映的是**真金白银的方向**。两者背离时，以资金量为准。

**强平记录**
密集强平往往是短期底/顶的信号——杠杆被清理后，市场结构才会变干净。

## 典型对话

```
你：分析一下 ETH 的盘面，多空博弈怎么样

AI：【价格】eth_usdt 3,240，24h +2.8%，标记价 3,239
   【仓位】全市场未平仓量 42.1 亿美元，24h +6.2% —— 价涨 OI 涨，新多入场
   【情绪】多空比 1.34（偏多）；恐惧贪婪 68（贪婪）
   【资金】24h 主动买/卖 = 1.12，买方略占优
   【成本】资金费率 +0.021%/8h，年化约 23% —— 多头持仓成本已偏高
   【强平】近 24h 空头强平占比 71%，3,180 附近有一波集中出清
   【结论】上涨由新增多头推动，但费率与多空比同时走高，仓位偏拥挤。
           3,180 是近期多空分水岭，跌破可能触发多头连环止损。
```

## 数据口径说明

- XT 的价格、K 线、盘口、资金费率标注为「**XT 行情数据**」
- 未平仓量、多空比、主动买卖量、强平、情绪指数、币种资料标注为「**TradeKit 聚合公开数据**」

两类数据的更新频率与覆盖范围不同，不要混用于精确计算。聚合数据存在延迟，**不适合高频或套利决策**。
