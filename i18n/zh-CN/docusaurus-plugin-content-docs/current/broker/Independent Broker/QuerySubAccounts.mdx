**类型:** GET

**描述:** `/v4/user/account`

仅支持使用**经纪商母账户**的 API Key 签名调用，返回当前经纪商名下的账户列表。

### 参数

| 名称 | 类型 | 是否必填 | 默认值 | 描述 | 取值范围 |
| --- | --- | --- | --- | --- | --- |
| accountId | long | 否 | - | 按账户 id 精确过滤 | 经纪商名下账户 id |
| accountName | string | 否 | - | 按账户名精确过滤 | - |
| level | string | 否 | - | 按账户层级过滤 | 1=母账户，2=子账户 |

返回结果为数组，不分页。查询子账户时传入 `level=2`。

### 请求示例

```bash
curl -X GET '{baseUrl}/v4/user/account?level=2' \
  -H 'validate-algorithms: HmacSHA256' \
  -H 'validate-appkey: {accessKey}' \
  -H 'validate-recvwindow: 60000' \
  -H 'validate-timestamp: {timestamp}' \
  -H 'validate-signature: {signature}'
```
