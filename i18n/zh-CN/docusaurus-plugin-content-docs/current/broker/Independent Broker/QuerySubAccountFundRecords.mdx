**类型:** GET

**描述:** `/v4/user/account/broker-sub/fund-records`

使用**经纪商母账户**的 API Key 签名调用，游标分页查询充值或提现流水，支持全历史查询。

### 参数

| 名称 | 类型 | 是否必填 | 默认值 | 描述 | 取值范围 |
| --- | --- | --- | --- | --- | --- |
| uid | long | 是 | - | 经纪商自身母账户 uid 或名下子账户 id | - |
| type | string | 是 | - | 流水类型 | IN_DEPOSIT（充值）、OUT_WITHDRAW（提现 / 子→母划出） |
| currency | string | 否 | - | 币种过滤 | - |
| status | string | 否 | SUCCESS | 状态过滤；`ALL` 返回全部 | SUBMIT、REVIEW、AUDITED、PENDING、SUCCESS、FAIL、CANCEL、ALL |
| startTime | long | 否 | - | 创建时间范围起点（毫秒）；起止均不传为全历史 | 毫秒时间戳 |
| endTime | long | 否 | - | 创建时间范围终点（毫秒） | 毫秒时间戳 |
| updateStartTime | long | 否 | - | 更新时间范围起点（毫秒） | 毫秒时间戳 |
| updateEndTime | long | 否 | - | 更新时间范围终点（毫秒） | 毫秒时间戳 |
| fromId | long | 否 | - | 游标（记录 `id`） | - |
| direction | string | 否 | NEXT | 翻页方向，不区分大小写 | NEXT、PREV |
| limit | int | 否 | 50 | 每页条数 | 1-100 |

### 请求示例

```bash
curl -X GET '{baseUrl}/v4/user/account/broker-sub/fund-records?uid=10645823292041&type=OUT_WITHDRAW&limit=50' \
  -H 'validate-algorithms: HmacSHA256' \
  -H 'validate-appkey: {accessKey}' \
  -H 'validate-recvwindow: 5000' \
  -H 'validate-timestamp: {timestamp}' \
  -H 'validate-signature: {signature}'
```

### 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| items[].id | long | 记录 id，兼作游标 |
| items[].userId | long | 经纪商母账户 uid |
| items[].accountId | long | 账户 id |
| items[].type | string | 流水类型，如 `IN_DEPOSIT`、`OUT_WITHDRAW`、`OUT_SUB_TRANSFER_OUT`（子→母划出） |
| items[].currency | string | 币种 |
| items[].chain | string | 链；内部划转为 `null` |
| items[].amount | string | 原币种金额 |
| items[].amountU | string | 折 U 金额（按记录时点价格） |
| items[].fee | string | 手续费 |
| items[].status | string | 状态：SUBMIT / REVIEW / AUDITED / PENDING / SUCCESS / FAIL / CANCEL |
| items[].createdTime | long | 创建时间（毫秒） |
| items[].updatedTime | long | 更新时间（毫秒） |
| hasPrev | boolean | 是否有上一页 |
| hasNext | boolean | 是否有下一页 |
