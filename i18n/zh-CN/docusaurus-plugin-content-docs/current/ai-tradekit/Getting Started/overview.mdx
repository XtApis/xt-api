# XT AI TradeKit 概览

**XT AI TradeKit** 是 XT.COM 面向 AI Agent 的原生交易套件。安装之后，你可以直接用自然语言让 AI 助手查行情、做盘面分析、研究币种、看公告快讯、管理资产并下单交易——不需要自己写一行 API 调用代码。

> 这是原「XT Exchange Plugin for Claude Code」的下一代版本。相比插件版，TradeKit 把能力拆成 **本地 MCP 工具层 + 场景化 Skill 层**，支持任意兼容 MCP 的客户端（Claude Code / Cursor / Codex 等），并新增了聚合市场数据、币种研究与新闻资讯能力。

---

## 什么是 Skills 和 MCP

| 概念 | 作用 |
|------|------|
| **MCP（Model Context Protocol）** | 一套让 AI 客户端调用外部工具的标准协议。TradeKit 提供一个**完全本地运行**的 MCP server，把 XT 的接口封装成 39 个结构化工具。 |
| **Skill** | 写给 AI 的领域说明书：告诉它什么场景该用哪些工具、怎么和你交互确认、结果怎么呈现。有了 Skill，你不用再往对话里粘贴接口文档。 |

两层配合的结果是：你说「用 100 U 市价买点 BTC」，AI 知道要先查交易对规则、换算精度、展示参数、等你确认，再调用下单工具。

## 架构

```
AItradekit/
├── mcp/                      # 本地 MCP server（Python，stdio，不依赖任何云端服务）
│   ├── server.py             # 39 个工具
│   └── xt_tradekit/          # XT 现货/合约客户端 + 聚合数据 + 新闻
├── skills/                   # 场景化 Skills
│   ├── xt-market/            # 行情查询
│   ├── xt-market-analysis/   # 深度盘面分析
│   ├── xt-coin-research/     # 币种研究与代币安全
│   ├── xt-news/              # 新闻快讯与 XT 公告
│   ├── xt-spot-trade/        # 现货交易
│   ├── xt-futures-trade/     # U 本位永续合约
│   ├── xt-assets/            # 资产（余额/划转/提币）
│   └── xt-tradekit-setup/    # 一键安装/更新
├── install.sh                # 一键安装脚本
└── setup-credentials.sh      # API Key 配置脚本（本地终端运行）
```

- **MCP 层**：统一的结构化工具，任意 MCP 客户端可调用。全本地运行，API Key 不出本机。
- **Skill 层**：决定何时用哪个工具、交互与确认流程、输出规范。

## 能力一览

### 行情与分析（无需 API Key）

- **现货行情**：实时价格、24h 涨跌、盘口深度、K 线、涨跌幅/成交额榜、交易对规则
- **合约行情**：最新价/标记价/指数价、盘口、K 线、当前与历史资金费率、合约规格
- **聚合市场数据**：全市场未平仓量、多空比、主动买卖量、强平记录、恐惧贪婪指数、全球市值概览
- **币种研究**：市值排名、FDV、流通/总供应、历史最高、项目简介；链上代币安全检查（蜜罐、买卖税、开源、增发权限、持仓集中度）
- **新闻资讯**：XT 官方公告（10 种语言）+ 公告关键词搜索 + 聚合加密快讯（中/英）

### 交易与资产（需要 API Key）

- **现货**：余额、当前挂单、历史订单、限价/市价下单、撤单、全部撤单
- **U 本位永续**：账户权益、持仓、当前委托、开平仓、撤单、历史订单
- **资产**：账户间划转（SPOT / LEVER / FUTURES_U / FUTURES_C / FINANCE）、提币、充提链与手续费查询

## 核心特点

**一套接口打通现货与合约**
行情、分析、下单、持仓、资产在同一个会话里完成，不用在多个工具之间切换。

**从研究到执行的完整链路**
「为什么这个币在涨」→ 查快讯与公告 → 看盘面与多空博弈 → 检查代币安全 → 换算仓位 → 确认下单，全程一条对话。

**渐进式交互**
AI 一次只问一个关键问题，而不是甩给你一张长表单。缺什么参数问什么。

**默认安全**

- 本地 MCP：server 跑在你本机，凭证存本地文件（权限 600），不经过任何云端服务
- 密钥不进对话：助手只能通过 `xt_credentials_status` 查看**掩码状态**，Skill 层明令禁止读取凭证文件或向你索要密钥
- 强制确认：下单/撤单/划转前展示完整参数；提币展示完整地址并二次确认
- 只读模式：`XT_TRADEKIT_READONLY=1` 可在 server 层禁用一切写操作

| 项目 | 要求 |

| Python | 3.10+ |

| 操作系统 | macOS / Linux（Windows 建议使用 WSL） |
