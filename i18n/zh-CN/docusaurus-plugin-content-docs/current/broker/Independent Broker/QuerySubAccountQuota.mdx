**类型:** GET

**描述:** `/v4/user/account/broker-sub/info`

使用**经纪商母账户**的 API Key 签名调用，查询独立经纪商的子账户配额与使用情况。

### 参数

无（仅需请求头鉴权）。

### 请求示例

```bash
curl -X GET '{baseUrl}/v4/user/account/broker-sub/info' \
  -H 'validate-algorithms: HmacSHA256' \
  -H 'validate-appkey: {accessKey}' \
  -H 'validate-recvwindow: 5000' \
  -H 'validate-timestamp: {timestamp}' \
  -H 'validate-signature: {signature}'
```

### 响应示例

```json title="Response"
{
  "rc": 0,
  "mc": "SUCCESS",
  "result": {
    "subAccountQty": 6,
    "maxSubAccountQty": 50000,
    "apiKeyLimitPerAccount": 10
  }
}
```

### 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| subAccountQty | int | 已创建子账户数量 |
| maxSubAccountQty | int | 子账户数量上限 |
| apiKeyLimitPerAccount | int | 每个子账户可创建的 API Key 数量上限 |
