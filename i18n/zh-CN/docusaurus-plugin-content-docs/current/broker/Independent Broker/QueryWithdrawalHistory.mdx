**生产地址:** `https://sapi.xt.com`

**类型:** GET

**描述:** `/v4/withdraw/history`

使用**子账户自己的 API Key** 签名调用，`QUERY` 权限即可。

### 参数

| 名称 | 类型 | 是否必填 | 默认值 | 描述 | 取值范围 |
| --- | --- | --- | --- | --- | --- |
| currency | string | 否 | - | 币种名称 | - |
| chain | string | 否 | - | 转账网络 | - |
| status | string | 否 | - | 提现状态 | SUBMIT、REVIEW、AUDITED、AUDITED_AGAIN、PENDING、SUCCESS、FAIL、CANCEL |
| fromId | long | 否 | - | 上次分页记录 id | - |
| direction | string | 否 | NEXT | 分页方向 | NEXT、PREV |
| limit | int | 否 | 10 | 每页记录数 | 1-200 |
| startTime | long | 否 | - | 查询开始时间 | 毫秒时间戳 |
| endTime | long | 否 | - | 查询结束时间 | 毫秒时间戳 |

### 请求示例

```bash
curl -X GET 'https://sapi.xt.com/v4/withdraw/history?currency=usdt&chain=Ethereum&limit=100' \
  -H 'validate-algorithms: HmacSHA256' \
  -H 'validate-appkey: {子账户accessKey}' \
  -H 'validate-recvwindow: 60000' \
  -H 'validate-timestamp: {timestamp}' \
  -H 'validate-signature: {signature}'
```
