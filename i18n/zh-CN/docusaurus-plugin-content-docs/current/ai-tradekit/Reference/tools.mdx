# 工具参考

`xt-tradekit` 本地 MCP server 提供的全部 39 个工具。标注 🔑 的需要 API Key。

---

## 现货行情（5）

| 工具 | 说明 | 参数 |
|------|------|------|
| `xt_spot_ticker` | 24h 行情：最新价、开高低、涨跌幅、成交量额 | `symbol` |
| `xt_spot_top_movers` | USDT 交易对榜单 | `direction`=`gainers`/`losers`/`volume`，`limit`=10 |
| `xt_spot_depth` | 盘口买卖档 | `symbol`, `limit`=10 |
| `xt_spot_klines` | K 线 | `symbol`, `interval`=`1h`, `limit`=24 |
| `xt_spot_symbol_info` | 交易对规则：精度、最小下单额 | `symbol` |

## 合约行情（6）

| 工具 | 说明 | 参数 |
|------|------|------|
| `xt_futures_ticker` | 最新价、标记价、指数价、买一卖一 | `symbol` |
| `xt_futures_depth` | 盘口 | `symbol`, `level`=10 |
| `xt_futures_klines` | K 线 | `symbol`, `interval`=`1h`, `limit`=24 |
| `xt_futures_funding_rate` | 当前资金费率 + 下次结算时间 | `symbol` |
| `xt_futures_funding_rate_history` | 历史资金费率序列 | `symbol`, `limit`=10 |
| `xt_futures_contract_info` | 每张面值、精度、最大杠杆 | `symbol` |

> K 线 `interval` 可选：`1m` `5m` `15m` `30m` `1h` `4h` `1d` `1w`

## 标记说明

- 🔑 需要 API Key
- ⚠️ **写操作**：调用前必须向用户展示完整参数并获得明确确认；`XT_TRADEKIT_READONLY=1` 时被 server 层直接拒绝

## 通用约定

- **交易对格式**：小写下划线，`btc_usdt`
- **合约数量单位**：张（整数），下单前用 `xt_futures_contract_info` 换算
- **开平方向**：开多 `BUY+LONG` / 开空 `SELL+SHORT` / 平多 `SELL+LONG` / 平空 `BUY+SHORT`
- **划转账户类型**：`SPOT` `LEVER` `FUTURES_U` `FUTURES_C` `FINANCE`
