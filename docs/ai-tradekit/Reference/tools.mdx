# Tools Reference

All 39 tools provided by the local `xt-tradekit` MCP server. Those marked 🔑 require an API Key.

---

## Spot Market Data (5)

| Tool | Description | Parameters |
|------|-------------|------------|
| `xt_spot_ticker` | 24h data: last price, OHLC, change, volume and turnover | `symbol` |
| `xt_spot_top_movers` | USDT pair rankings | `direction`=`gainers`/`losers`/`volume`, `limit`=10 |
| `xt_spot_depth` | Order book levels | `symbol`, `limit`=10 |
| `xt_spot_klines` | Klines | `symbol`, `interval`=`1h`, `limit`=24 |
| `xt_spot_symbol_info` | Symbol rules: precision, minimum notional | `symbol` |

## Legend

- 🔑 Requires an API Key
- ⚠️ **Write operation**: full parameters must be shown to the user and explicitly confirmed before the call; rejected outright at the server layer when `XT_TRADEKIT_READONLY=1`

## Common Conventions

- **Symbol format**: lowercase with an underscore, `btc_usdt`
- **Futures quantity unit**: contracts (integer); convert with `xt_futures_contract_info` before ordering
- **Open/close direction**: open long `BUY+LONG` / open short `SELL+SHORT` / close long `SELL+LONG` / close short `BUY+SHORT`
- **Transfer account types**: `SPOT` `LEVER` `FUTURES_U` `FUTURES_C` `FINANCE`
