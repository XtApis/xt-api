# 币种研究与代币安全

由 `xt-coin-research` skill 驱动。无需 API Key。

---

## 基本面

`market_coin_profile(coin)` —— `coin` 可以是 `btc` 或 `bitcoin`。返回：

- 市值排名、当前市值、**FDV（完全稀释估值）**
- 流通供应 / 总供应
- 历史最高价（ATH）及距今回撤
- 所属赛道分类、项目简介

```
你：ARB 这个币基本面怎么样
AI：【ARB / Arbitrum】市值排名 #42，市值 12.4 亿美元
   FDV 38.7 亿美元 —— FDV/市值 ≈ 3.1，仍有大量代币未解锁
   流通 32 亿 / 总量 100 亿（32%）
   ATH $2.40（2023-01），距今 -87%
   赛道：Layer 2、Ethereum 生态
```

**FDV / 市值比**是判断解锁压力的关键：比值越高，未流通代币越多，未来抛压越大。

## 多币对比

```
你：对比一下 ARB、OP、MATIC
```

助手会并行取三者资料，按市值、FDV、流通率、赛道横向列表，并结合[行情](./MarketData)给出相对表现。

## 链上代币安全检查

`market_token_security(chain, contract_address)` —— 买小市值代币前的必要动作。

检查项：

| 项目 | 风险含义 |
|------|---------|
| **蜜罐（honeypot）** | 能买不能卖，资金直接锁死 |
| **买入/卖出税** | 高额税率吞噬本金，10%+ 需高度警惕 |
| **是否开源** | 未开源合约无法审计其行为 |
| **增发权限（mint）** | 项目方可无限增发稀释持有者 |
| **持仓集中度** | 前几大地址占比过高，单地址即可砸盘 |

```
你：检查一下这个合约安全吗 0xabc...def（BSC）

AI：【代币安全检查 · BSC】
   ✅ 非蜜罐
   ⚠️ 买入税 5% / 卖出税 12% —— 卖出税明显偏高
   ✅ 合约已开源
   ❌ 存在增发权限，owner 未放弃
   ⚠️ 前 10 地址持有 68%，集中度高
   【结论】高风险。增发权限未放弃 + 高卖出税 + 持仓集中，不建议大额参与。
```

> 安全检查基于链上公开数据的自动化扫描，**能识别常见陷阱，但不能保证没有风险**。合约通过检查也不代表项目方不会 rug。
